# 3. STANDARDS.md - 架构规范与红线禁令

## 绝对红线（Inviolable Rules）
1. **严禁无根代码**：视觉引擎必须基于真实音频频谱（FFT）或离线提取的关键帧驱动，严禁使用纯随机无逻辑震荡。
2. **严禁故事脱靶**：每一首歌必须在 `WorldBible` 中挂载明确的时间线坐标与角色动机，严禁创作孤立无援的空心 MV。
3. **严禁从零发明轮子**：自研视听框架依托现代成熟技术栈（Vue 3 + Three.js / WebGL / Pixi.js / Shaders），专注在“算法表现层与参数映射”，严禁重复实现基础底层。
4. **单期可归档性**：所有 Episode 必须包含完整工程资产（音频 Stems、视觉配置文件、世界观日志），确保秒级复现与迁移。
5. **视觉带宽远超主动输入原则（The High-Bandwidth Perception Law）**：人类视觉吸收与感知带宽极高（每秒数兆比特并行吞吐），而主动打字输入是极低带宽、高摩擦的串行通道。一切系统交互与世界展示，严禁强制要求用户像老旧 CLI 一样纯靠敲命令输入才能推进；必须以**极高密度的视听沉浸、空间化布局、直觉交互（点击/悬浮/波形/按键快捷映射）为第一通道**，文本命令只作为深层解锁的高阶仪式感点缀。
