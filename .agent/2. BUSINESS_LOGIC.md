# 2. BUSINESS_LOGIC.md - 核心生产流与时序闭环

## 1. 单期作品生产时序（Production Cycle）

```mermaid
sequenceDiagram
    autonumber
    participant WB as World Bible (世界圣经)
    participant MP as Music Pipeline (AI人声工业流)
    participant VE as Visual Engine (自研视听引擎)
    participant EP as Episode Asset (归档发行包)

    WB->>MP: 提取剧情事件、角色情绪与歌词核心隐喻
    MP->>MP: Suno/Udio 灵感原型 -> 分轨 (Stems) -> 人声音色精修与混音
    MP->>VE: 导出高保真母带与 FFT 预提取特征 (BPM/Beat/Frequencies)
    WB->>VE: 注入本期角色符号 DNA (< > / @) 与剧情突变色
    VE->>VE: 运行着色器管线，生成 1080p/4K 60fps 动态符号映像
    VE->>EP: 音画合成，封装归档发布包 (EPxxx)
    EP->>WB: 回写已解锁世界历史，更新未解悬念树
```

## 2. 跨媒介演进状态机（Transmedia Lifecycle）
- **State 1: Sandbox (0-14天)**：60秒垂直切片，验证参数联动与受众反应。
- **State 2: Serialized Music (1-12个月)**：12期连续单曲，建立铁粉认知与考据社群。
- **State 3: Interactive ARG / Visual Novel (12-24个月)**：利用 WebGL/Vue 打造终端解谜互动。
- **State 4: Standalone Game (2-3年)**：视听引擎资产直接导入 Godot/Unity，发布 Steam 独立游戏。
