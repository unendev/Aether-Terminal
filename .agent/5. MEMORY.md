# 5. MEMORY.md - 经验沉淀与底层认知

## 核心反直觉认知（Counter-Intuitive Truths）
1. **面具效应（Masking Effect）**：逼真写实的人脸让观众觉得是“别人的故事”；极简的符号（如字符、几何、点阵）强迫人类大脑调用自身记忆与情感参与填补，产生“我自己的故事”这种最深刻的心理投射。
2. **形式 vs 语法**：ASCII 画画会审美疲劳；但将代码作为一种“带有镜头纵深、剧情突变色、语义暗号、角色符号 DNA”的视觉语法，具有跨周期的抗脆弱性。
3. **世界观的构建陷阱**：不要写线性小说剧本，而要建立《世界圣经》（World Bible：核心不可变规则、未解悬念树、阵营张力、角色动机库）。每首歌都是一次数据库切片访问。
4. **视觉吞吐 vs 输入摩擦**：人类视觉系统是大脑最高速的并行总线，能在 100ms 内并行解码数万维度的光影、韵律、拓扑与情绪暗示；而键盘敲击是逐字串行的低速物理动作。因此，视觉是“高吞吐信息泵”，文本交互是“确认性仪式”。交互设计永远不要用繁重的手动打字卡死人类的高速感知流。
