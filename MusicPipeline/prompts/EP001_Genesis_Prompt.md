# EP001: Genesis Protocol // 创世纪协议 (Suno Production Spec)

## 一、 音乐定位与 YouTube 爆款标准
- **对标风格**：Mili (`world.execute(me);`), Porter Robinson (`Shelter`), Eve (`Kaibutsu` / `Dramaturgy`), KAMITSUBAKI (KAF 花谱), NieR Automata OST (`Weight of the World`).
- **情绪曲线**：
  - 0:00 - 0:35 【初生迟疑】：单音三角波、终端按键打字底噪、极简电钢，AI 尝试发声的颤抖与断续。
  - 0:35 - 1:15 【旋律展开】：轻快温暖的 Glitch-Hop 律动加入，充满好奇与探索感。
  - 1:15 - 1:55 【副歌爆发】：重低音合成器（808 Sub-Bass）下潜、宽广的合成器铺底、高亢空灵的女声切入，情绪瞬间升空！
  - 1:55 - 2:30 【记忆交织】：主副歌变奏，加入弦乐残响与齿音呼吸。
  - 2:30 - 3:00 【大高潮】：双层人声和声、全频段爆发。
  - 3:00 - 3:20 【尾奏留白】：突然抽空所有乐器，只剩纯人声与一行代码敲击声。
