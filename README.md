# Aether-Terminal（以太终端）

> **项目定位**：AI 原生视听宇宙生产系统（Audio-Visual Lore System）。  
> **核心使命**：维护一套自研的程序化符号视听框架（Visual Engine）与 AI 人声工业管线（Music Pipeline），以连续演进的宏大叙事世界观（World Bible）为基石，持续发布连贯的视听档案（Episodes），最终沉淀为具备独立游戏与跨媒介衍生能力的常青 IP。

## 目录索引

- **`WorldBible/`**：世界圣经核心。世界规则、文明纪元时间线、阵营冲突与未解悬念树。
- **`VisualEngine/`**：自研视听渲染框架。FFT 音频参数提取器、ASCII/着色器粒子系统、动态运镜预设。
- **`MusicPipeline/`**：AI 音乐与人声工程链。词曲 Prompt、分轨 Stems、人声音色库、混音母带工程。
- **`LoreDatabase/`**：世界观实体数据库。角色档案（Characters）、阵营（Factions）、事件（Events）。
- **`Episodes/`**：按期归档的各期单曲与 MV 视听资产包（`EP001/`, `EP002/`...）。
- **`Docs/`**：长期架构方案、路线图与技术笔记。
- **`.agent/`**：AI Pair Programming 治理规范与项目沉淀记录。
